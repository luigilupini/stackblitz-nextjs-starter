# nextjs-interview-solutions (private)

Interviewer reference for the Next.js / React interview. `app/page.tsx` contains
`Solution 1` … `Solution 5`, matching `Exercise 1` … `Exercise 5` in the
candidate-facing `nextjs-interview-exercises` repo.

Stack: Next.js 15 (App Router) · React 19 · TypeScript · Tailwind 4 · DaisyUI 5 · PokéAPI

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
npm run lint
npm run typecheck
```
